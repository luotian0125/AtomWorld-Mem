# AtomWorld-Mem Project Page

Static project page for **AtomWorld-Mem: Memory-Restored World States for Long-Horizon Atomistic Evolution**.

## Publish with GitHub Pages

Upload the contents of this directory to the root of the public Pages repository, then select **Settings → Pages → Deploy from a branch → main / (root)**.

The page uses only local HTML, CSS, JavaScript, SVG, PNG, and GIF assets; no build step or external framework is required.

## Important files

- `index.html` — page structure and paper content
- `assets/css/style.css` — responsive visual design
- `assets/js/main.js` — lightweight reveal, navigation, citation-copy, and lazy animation behavior
- `assets/images/clustering-dynamics.gif` — long-horizon clustering animation

When an arXiv identifier is available, replace the disabled **Paper soon** element in `index.html` with an anchor pointing to the paper URL, and update the BibTeX block in the Citation section.
